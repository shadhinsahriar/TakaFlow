# TakaFlow — Personal Finance Manager

TakaFlow is a modern personal finance management web application designed to help users organize their finances, track transactions, manage budgets, monitor savings goals, and keep track of loans and debts through a clean, interactive dashboard.

**Project Status:** Frontend Demo — Backend integration is not yet implemented.

## Live Demo

**[Launch TakaFlow — Personal Finance Manager](https://shadhinsahriar.github.io/TakaFlow/)**

> **Demo Notice:** The live version currently uses sample data to demonstrate the application's interface and features. User authentication, a backend database, and cloud synchronization are not yet implemented. Do not use the demo to store real financial information.

## Features

- **Dashboard:** Get an overview of financial activity.
- **Transaction Management:** Track income and expenses.
- **Budget Management:** Organize spending by category.
- **Savings Goals:** Monitor progress toward financial goals.
- **Loans and Debts:** Keep track of money borrowed and lent.
- **Financial Analytics:** Explore financial activity through visual charts and summaries.
- **Currency Selection:** Support for Bangladeshi Taka (BDT) and other available currencies.
- **Data Backup:** Local data export and import functionality, where implemented.

*Feature availability may vary while development is in progress.*

## Technology Stack

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages for static website hosting

TakaFlow is designed as a lightweight, single-page web application without requiring a frontend framework or build process.

## Current Limitations

TakaFlow is currently a frontend demonstration. The following capabilities are not yet available:

- User registration and login
- Google account authentication
- Backend API and cloud database
- Automatic synchronization across devices
- Cloud-based backup and recovery

The current demo uses sample data to showcase the application's design and user experience. Backend integration and cloud synchronization are planned for future development.

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/shadhinsahriar/TakaFlow.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No package installation or build process is required for the standalone frontend.

## Deployment

TakaFlow is hosted using GitHub Pages. Updates pushed to the configured publishing branch can be deployed through GitHub Pages settings.

Future backend functionality will require additional implementation and appropriate hosting services.
